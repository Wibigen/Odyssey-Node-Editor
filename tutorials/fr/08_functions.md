# Vos propres fonctions

Les fonctions permettent de réutiliser un groupe de nœuds.

## Définir

1. Ajoutez **Define function** (Fonctions). Donnez-lui un nom, des paramètres (petites cases : type + nom, **+** pour en ajouter) et un type de retour.
2. Construisez son corps après sa broche **next**. Utilisez **Return** pour renvoyer une valeur.

## Appeler

Ajoutez **Call function**, choisissez votre fonction : ses broches d'entrée sont vos paramètres. Utilisez-la dans un hook, une boucle, une autre fonction.

## Bonnes habitudes

* Nommez les fonctions d'après ce qu'elles font (`respawnCoins`).
* Sélectionnez les nœuds d'une fonction et appuyez sur **Ctrl+G** pour les encadrer (voir *Groupes, commentaires et bibliothèque*).
* Enregistrez une fonction que vous utilisez dans plusieurs mods avec **Bibliothèque > Enregistrer la sélection dans la bibliothèque**.
