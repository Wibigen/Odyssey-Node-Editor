# Préférences, thèmes et raccourcis

## Préférences (Ctrl+,)

* **Démarrage et fichiers** : ce qui s'ouvre au lancement, la sauvegarde automatique, ce qu'affiche *Fichier > Nouveau*.
* **Apparence** : **Thème** (sombre, clair, plus ceux des plugins) et **couleur d'accent**.
* **Canevas** : grille, magnétisme, liens de la sélection au premier plan, groupement automatique, menu sur lien relâché.
* **Aperçu du code** : surlignage, numéros de ligne, retour à la ligne, taille de police.
* **Interface** : taille du texte.
* **Avancé** : comment les fonctions du jeu sont appelées, comment les hooks sont installés.

Affichage > Thème change rapidement l'apparence.

## Langue

**Affichage > Langue** (l'icône de globe, pour la retrouver dans n'importe quelle langue) fait passer l'interface entre l'anglais, le français, l'allemand, l'espagnol, l'italien, le néerlandais, le russe, le japonais et le chinois. L'anglais est la langue par défaut. Le programme propose de redémarrer pour appliquer le changement. Le contenu des plugins (par exemple les descriptions des fonctions Dear ImGui) reste en anglais.

## Raccourcis clavier

**Outils > Raccourcis clavier…** modifie n'importe quel raccourci. Valeurs par défaut :

| Touche | Action |
|---|---|
| Ctrl+Maj+F | Ajouter une fonction du jeu |
| Ctrl+Maj+K | Ajouter une fonction de plugin |
| Ctrl+F | Rechercher dans le graphe |
| Ctrl+Z / Ctrl+Y | Annuler / rétablir |
| Ctrl+D, Suppr, Ctrl+A | Dupliquer, supprimer, tout sélectionner |
| Ctrl+G, Ctrl+Maj+C, Ctrl+L | Grouper, commenter, organiser |
| Ctrl+I | Importer du C++ |
| F, Ctrl+J | Ajuster la vue, afficher/masquer la sortie |
| Ctrl+E, F5 | Écrire dans le projet, compiler |
| Ctrl+N / O / S | Nouveau, ouvrir, enregistrer |
| Ctrl+Maj+S | Enregistrer sous… |
| F1 | Tutoriels |
