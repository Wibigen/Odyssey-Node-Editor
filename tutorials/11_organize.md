# Groups, comments and the library

## Groups

Select nodes, press **Ctrl+G**: a frame with a title appears. Drag the title bar to move all nodes together. Edit the name, colour and members from the group's menu. Preference: drop a node inside a frame to add it to the group.

## Comments

**Ctrl+Shift+C** (or right-click the canvas > *Comment here*) adds a free-text note.

## Tidy up

**Ctrl+L** arranges the graph automatically (all nodes, or only the selection).

## The library

Reuse your own work across projects.

* **Library > Save selection to library…** stores a function (with everything it uses) or a template as a `.odnf` file in your data folder.
* Saved entries appear at the bottom of the **Blocks** list and in the **Library** menu. Double-click or drag one to insert it (inside a group).

## Files

* **File > Save as…**: `.odn` files; autosave also keeps your session.
* **File > Save as startup graph**: what **File > New** opens.
* **New from template**: ready graphs (for instance from plugins).
