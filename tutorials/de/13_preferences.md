# Einstellungen, Designs und Kürzel

## Einstellungen (Strg+,)

* **Start und Dateien**: was beim Start geöffnet wird, automatische Sicherung, was *Datei > Neu* zeigt.
* **Erscheinungsbild**: **Design** (dunkel, hell, plus Designs aus Plugins) und **Akzentfarbe**.
* **Zeichenfläche**: Raster, Einrasten, Verbindungen der Auswahl im Vordergrund, automatisches Gruppieren, das Menü bei losgelassenen Verbindungen.
* **Codevorschau**: Hervorhebung, Zeilennummern, Umbruch, Schriftgröße.
* **Oberfläche**: Textgröße.
* **Erweitert**: wie Spielfunktionen aufgerufen und Hooks installiert werden.

Ansicht > Design ändert das Aussehen schnell.

## Sprache

**Ansicht > Sprache** (das Globus-Symbol, damit Sie es in jeder Sprache finden) schaltet die Oberfläche zwischen Englisch, Französisch, Deutsch, Spanisch, Italienisch, Niederländisch, Russisch, Japanisch und Chinesisch um. Englisch ist die Standardsprache. Das Programm bietet einen Neustart an, um die Änderung zu übernehmen. Plugin-Inhalte (zum Beispiel die Beschreibungen der Dear-ImGui-Funktionen) bleiben auf Englisch.

## Tastenkürzel

**Werkzeuge > Tastenkürzel…** ändert jedes Kürzel. Standardwerte:

| Taste | Aktion |
|---|---|
| Strg+Umschalt+F | Spielfunktion hinzufügen |
| Strg+Umschalt+K | Plugin-Funktion hinzufügen |
| Strg+F | Im Graphen suchen |
| Strg+Z / Strg+Y | Rückgängig / Wiederholen |
| Strg+D, Entf, Strg+A | Duplizieren, Löschen, Alles auswählen |
| Strg+G, Strg+Umschalt+C, Strg+L | Gruppieren, Kommentieren, Anordnen |
| Strg+I | C++ importieren |
| F, Strg+J | Ansicht einpassen, Ausgabe ein-/ausblenden |
| Strg+E, F5 | Ins Projekt schreiben, Kompilieren |
| Strg+N / O / S | Neu, Öffnen, Speichern |
| Strg+Umschalt+S | Speichern unter… |
| F1 | Tutorials |
