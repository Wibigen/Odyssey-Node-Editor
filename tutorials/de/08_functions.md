# Ihre eigenen Funktionen

Mit Funktionen verwenden Sie eine Gruppe von Knoten wieder.

## Definieren

1. Fügen Sie **Define function** (Funktionen) hinzu. Geben Sie ihr einen Namen, Parameter (kleine Felder: Typ + Name, **+** zum Hinzufügen) und einen Rückgabetyp.
2. Bauen Sie ihren Rumpf nach ihrem Pin **next**. Mit **Return** geben Sie einen Wert zurück.

## Aufrufen

Fügen Sie **Call function** hinzu und wählen Sie Ihre Funktion: Ihre Eingangspins sind Ihre Parameter. Verwenden Sie sie in einem Hook, einer Schleife, einer anderen Funktion.

## Gute Gewohnheiten

* Benennen Sie Funktionen nach dem, was sie tun (`respawnCoins`).
* Wählen Sie die Knoten einer Funktion und drücken Sie **Strg+G**, um sie einzurahmen (siehe *Gruppen, Kommentare und die Bibliothek*).
* Speichern Sie eine Funktion, die Sie in mehreren Mods nutzen, mit **Bibliothek > Auswahl in der Bibliothek speichern**.
