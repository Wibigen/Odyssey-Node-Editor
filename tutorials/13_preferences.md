# Preferences, themes and shortcuts

## Preferences (Ctrl+,)

* **Startup and files**: what opens at start, autosave, what *File > New* shows.
* **Appearance**: **Theme** (dark, light, plus themes from plugins) and **accent colour**.
* **Canvas**: grid, snapping, links of the selection on top, auto-group, the menu on released links.
* **Code preview**: highlighting, line numbers, wrapping, font size.
* **Interface**: text size.
* **Advanced**: how game functions are called, how hooks are installed.

View > Theme changes the look quickly.

## Language

**View > Language** (the globe icon, so you can find it in any language) switches the interface between English, French, German, Spanish, Italian, Dutch, Russian, Japanese and Chinese. English is the default. The program offers to restart to apply the change. Plugin content (for example the Dear ImGui function descriptions) stays in English.

## Keyboard shortcuts

**Tools > Keyboard shortcuts…** changes any shortcut. Defaults:

| Key | Action |
|---|---|
| Ctrl+Shift+F | Add game function |
| Ctrl+Shift+K | Add plugin function |
| Ctrl+F | Find in the graph |
| Ctrl+Z / Ctrl+Y | Undo / redo |
| Ctrl+D, Del, Ctrl+A | Duplicate, delete, select all |
| Ctrl+G, Ctrl+Shift+C, Ctrl+L | Group, comment, arrange |
| Ctrl+I | Import C++ |
| F, Ctrl+J | Fit view, show/hide output |
| Ctrl+E, F5 | Write to project, compile |
| Ctrl+N / O / S | New, open, save |
| Ctrl+Shift+S | Save as… |
| F1 | Tutorials |
