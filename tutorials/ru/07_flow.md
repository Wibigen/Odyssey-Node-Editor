# Управление потоком

Блоки **Flow** определяют, *какие* ноды выполняются и *сколько раз*.

| Блок | Что делает |
|---|---|
| **Branch (if / else)** | Условие **c**: выполняет путь **then** или **else**, затем продолжает. |
| **Switch** | Выбирает путь по целому числу; случаи редактируются в виде маленьких ячеек кнопкой **+**. |
| **For loop** | Повторяет путь N раз; индекс — выход. |
| **While loop** | Повторяет, пока условие истинно. |
| **Return** | Выходит из текущей функции или хука, при необходимости со значением. |

## Как читать поток

Следуйте за белыми стрелками. У ноды с двумя выходами выполнения (Branch) два возможных продолжения; позже они могут сойтись в общей ноде.

## Советы

* Держите циклы короткими: хуки работают в главном потоке игры, каждый кадр.
* Чтобы сделать что-то **один раз** при смене условия, храните предыдущее состояние в **Глобальной переменной**.
* Оформите повторяющуюся идею как собственную функцию (следующее руководство).
