# Ваш первый мод

Цель: выполнять что-то **раз в секунду** во время игры. Пример графа делает именно это; здесь вы собираете его сами, чтобы понять каждую часть.

## 1. Хук игровой функции

1. Нажмите **Игровая функция…** (красная кнопка или Ctrl+Shift+F).
2. Найдите `exePlay` и выберите **StageScene::exePlay** (она выполняется каждый кадр, пока вы играете).
3. Выберите **Перехватить эту функцию**, оставьте режим *Сначала оригинал, затем мой граф* и нажмите **Добавить в граф**.

Появится красная нода **Hook StageScene::exePlay**. Белый пин **next** — место, где начинается ваша логика.

## 2. Подсчёт кадров

1. Добавьте **Глобальную переменную** (Переменные): тип `int`, имя `frames`, начальное значение `0`. Глобальная переменная сохраняет значение от кадра к кадру.
2. Добавьте **Set variable**, выберите `frames` и соедините **hook next → in**.
3. Добавьте **Get variable** `frames` и **Math (A + B)** типа `int`, B = `1`; соедините *Get → A*, *Math out → Set v*.

## 3. Действие каждые 60 кадров

1. Добавьте **Branch (if / else)** после Set variable.
2. Условие: **Compare** `(frames % 60) == 0` (нода *Math* с `%` и 60, подающая результат в *Compare* с `== 0`). Соедините результат с пином **c** ноды Branch.
3. На ветку **then** поместите нужное, например **Custom statement** `/* мой код */` или вызов игровой функции.

## 4. Просмотр кода

Откройте вкладку **Код C++**: там хук, переменная и `if`. Выберите ноду — её строки подсветятся.

## 5. Сборка и проверка

1. Вкладка **Проблемы** пуста? Отлично.
2. **Записать в проект** (Ctrl+E), затем **Скомпилировать** (F5).
3. Вкладка **Ryujinx** > *Установить мод и запустить*.

> Быстрее начать: **Файл > Новый из шаблона** (или пример графа в Настройки > Открывать при запуске) даёт готовый граф.
