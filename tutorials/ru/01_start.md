# Начало работы

**Odyssey Node Editor** позволяет создать мод для **Super Mario Odyssey 1.0.0**, не пиша C++ вручную. Вы соединяете **ноды** на холсте, а редактор пишет код для [exlaunch](https://github.com/shadowninja108/exlaunch). Компилируете вы по-прежнему в собственном проекте exlaunch.

## Идея за одну минуту

1. Нода **хука** означает: *«когда игра выполняет эту функцию, запусти мой граф»*.
2. Затем вы соединяете ноды: вызываете игровые функции, меняете переменные, проверяете условия, делаете циклы.
3. Вкладка **Код C++** сразу показывает результат.
4. **Записать в проект** кладёт код в ваш проект exlaunch, **Скомпилировать** собирает его, вкладка **Ryujinx** запускает игру с вашим модом.

## Что понадобится

* Папка с **OdysseyDecomp** (редактор читает список символов, чтобы знать каждую игровую функцию).
* **Проект exlaunch** (например, копия SMO-Exlaunch-Base), который можно собрать.
* *(необязательно)* Ryujinx для тестов.

## Окно программы

| Область | Что это |
|---|---|
| Меню и панель инструментов | Файл, Правка, Библиотека, Вид, Сервис, Плагины, Справка; самые частые значки |
| **Блоки** (слева) | Все блоки, которые можно добавить, с поиском |
| **Холст** (центр) | Ваш граф |
| **Инспектор** (справа) | Параметры выбранной ноды |
| **Вывод** (снизу) | Код C++, Includes, Проблемы, Сборка, Ryujinx |

Выберите **Справка > Обзор интерфейса**, чтобы пройти экскурсию, а затем читайте руководства по порядку:

1. *Настройка проекта*
2. *Ваш первый мод*
3. *Холст*, далее нужные вам темы.

**Важно:** редактор сам никогда не компилирует для Switch и не трогает файлы игры: он пишет C++ в проект, на который вы укажете.
