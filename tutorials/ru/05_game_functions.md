# Вызов и хук игровых функций

Нажмите **Игровая функция…** (Ctrl+Shift+F), чтобы искать по каталогу функций Super Mario Odyssey.

## Обозреватель

* Введите часть имени, класса или описания. Категории слева сужают список.
* Выберите функцию, чтобы увидеть её **сигнатуру, тип возврата, смещение и символ**.
* Звезда ☆ отмечает **избранное**; **Открыть на GitHub** запускает поиск в OdysseyDecomp (удобно, чтобы прочитать, что она делает на самом деле).

## Вызвать или перехватить?

| | **Вызвать эту функцию из моего мода** | **Перехватить эту функцию** |
|---|---|---|
| Смысл | *Мой граф вызывает эту игровую функцию* | *Когда игра вызывает её, запускается мой граф* |
| Нода | Нода в вашем потоке | Красная входная нода (без входа) |
| Типичное применение | `al::setPos(actor, …)`, `kill`, чтение значения | Выполнять код каждый кадр, при ударе, при подборе предмета |

### Аргументы вызова

Каждый аргумент — либо **Подключить ноду** (значение приходит по связи), либо **Фиксированное значение**: число, текст, bool, `Vector3` (поля X/Y/Z) или любое выражение C++.

### Результат

Вызов, возвращающий значение, может **сохранить его в переменную** (задайте имя в инспекторе) или **использоваться напрямую как значение** в другой ноде (*Использовать как значение* в инспекторе или контекстном меню).

## Режимы хука

| Режим | Что выполняется |
|---|---|
| **Сначала оригинал, затем мой граф** | Игровая функция, затем ваша логика (по умолчанию). |
| **Сначала мой граф, затем оригинал** | Ваша логика, затем игровая. |
| **Заменить оригинал** | Только ваш граф. |
| **Вручную** | Вы сами ставите ноды **Call original (Orig)** там, где нужно. |

В режиме *до* с возвращаемым значением выход **original result** содержит то, что вернула игра. При необходимости измените тип возврата или имена аргументов в инспекторе.

## Неверный тип возврата?

Каталог угадывает типы возврата по заголовкам. Если функция помечена `void`, но что-то возвращает, нажмите **Изменить…** рядом с типом возврата (предупреждение запросит подтверждение). Выбор запоминается.

## Вызов по имени

Для того, чего нет в каталоге, используйте **Call by name** (Функции): любая функция C++ по имени, например `sead::Mathf::sqrt(x)`. **Get scene object** покрывает `al::getSceneObj<T>(…)`.

## Стиль вызова

*Настройки > Дополнительно*: по умолчанию вызовы — обычный C++ (`rs::getPlayerActor(scene)`) либо по адресу. Одна нода может переопределить это (*Стиль вызова* в инспекторе). Хуки по умолчанию устанавливаются **по символу**; вариант со смещением — запасной.
