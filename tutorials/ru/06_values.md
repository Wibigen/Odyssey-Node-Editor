# Переменные, значения и математика

## Переменные (категория *Переменные*)

| Блок | Назначение |
|---|---|
| **Declare variable** | Локальная переменная (тип, имя, необязательное начальное значение). Живёт в потоке, где объявлена. |
| **Set variable** | Присвоить новое значение. |
| **Get variable** | Прочитать текущее значение (выход-значение, без пина выполнения). |
| **Global variable** | Сохраняет значение между кадрами и вызовами. *Declare variable* вне функции тоже становится глобальной. |
| **Constant (value)** | Фиксированное число, текст, bool или любое значение C++, которое вы введёте. |

Используйте **Дополнительно** в инспекторе для квалификаторов (`static`, `const`…) и массивов (размер и содержимое).

> Локальная переменная, объявленная в ветке, существует только в этой ветке (как в C++).

## Математика и логика

Отображаются маленькими квадратами:

* **Math (A + B)**: `+ - * / %` над двумя значениями (выберите тип).
* **Compare**: `== != < > <= >=`, возвращает bool.
* **Logic**: AND / OR; **NOT** инвертирует bool.

Подключите результат к условию **Branch**, к переменной или к аргументу вызова.

## Фиксированное значение или связь?

Каждый входной пин можно **подключить** к ноде или задать ему **фиксированное значение** (вводится в инспекторе). Подключённый вход скрывает своё фиксированное значение.

## Типы

Цвета пинов показывают типы; редактор не проверяет типы указателей между связями (например, `StageScene*` в `al::LiveActor*` — ошибка C++, которую вы увидите при сборке). Используйте **Cast** (Указатели и память), когда нужно преобразовать.
