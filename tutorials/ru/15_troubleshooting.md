# Устранение неполадок

| Проблема | Что попробовать |
|---|---|
| *Каталог функций пуст* | Сервис > Настройки: выберите папку OdysseyDecomp (с `data/file_list.yml`) и извлеките каталог. |
| Функция возвращает `void`, хотя не должна | Измените тип возврата (см. *Вызов и хук игровых функций*). |
| Вкладка *Проблемы* что-то показывает | Двойной щелчок по строке выделит ноду. Обычно это неподключённый вход или отсутствующая переменная. |
| Компиляция не находит заголовок | Добавьте его на вкладке **Includes** или исправьте пути include проекта. |
| Папка сборки повреждена | Сервис > **Восстановить базу exlaunch**. |
| В игре ничего не происходит | Установлен ли хук (верный символ)? Та ли это папка модов, которую загружает Ryujinx (вкладка Ryujinx)? Не отключён ли другой мод? |
| Игра падает | Указатель равен null или неверно смещение. Добавьте проверки **Is null?**; подтвердите смещения для версии 1.0.0. |
| Горячая клавиша не работает | Сервис > Горячие клавиши: её могли изменить. |
| Странная раскладка окна | Вид: покажите панель вывода (Ctrl+J); перетащите панели на нужные места. |

Сообщая о проблеме, приложите журнал **Сборки** (Сохранить журнал сборки).
