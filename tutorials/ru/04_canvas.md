# Холст: ноды, пины и связи

## Ноды и пины

У ноды **входные пины** слева и **выходные пины** справа.

* **Пины с белой стрелкой** задают **порядок выполнения**: нода запускается после ноды, подключённой к её пину *in*, и продолжает через *next*.
* **Цветные кружки** — это **значения**. Цвет зависит от типа (число, указатель, bool, текст…). Заполненный кружок подключён; пустой свободен.
* Неподключённый вход показывает **фиксированное значение**, которое вводится в инспекторе (`= 60`).

## Соединение

* **Перетащите от пина к другому пину** (выход к входу).
* Выход-значение может питать **несколько** входов; выход выполнения ведёт к **одной** следующей ноде.
* **Отпустите связь на пустом месте**: меню предложит *Игровая функция…*, *Функция плагина…* (если у плагина есть каталог) и все подходящие блоки; новая нода создаётся и подключается сама. (Отключается в Настройках.)
* Выберите ноду и нажмите **Delete**, чтобы удалить её; *Инспектор > Отсоединить* убирает только её связи.

## Навигация

| Действие | Как |
|---|---|
| Масштаб | Колесо мыши (Ctrl +/-) |
| Сдвиг | Зажмите **среднюю кнопку** и тяните |
| Показать всё | **F** |
| Выбрать несколько | Рамка на пустом месте; Ctrl+A — всё |
| Дублировать / удалить | Ctrl+D / Delete |
| Отменить / повторить | Ctrl+Z / Ctrl+Y |
| Найти ноду | Ctrl+F по графу (значок поиска) |
| Навести порядок | Ctrl+L автоматически раскладывает ноды |

## Добавление блоков

* **Двойной щелчок** по блоку или **перетаскивание** из списка **Блоки**.
* **Правый щелчок** по пустому холсту даёт те же варианты, плюс *Добавить комментарий здесь*.
* Поле фильтра над списком ищет по названиям и описаниям.

## Цвета

У каждого вида нод свой цвет заголовка. Ноды, пришедшие из **плагина**, дополнительно окружены мягким свечением цвета плагина, чтобы их было видно с одного взгляда.
