# Настройки, темы и горячие клавиши

## Настройки (Ctrl+,)

* **Запуск и файлы**: что открывается при старте, автосохранение, что показывает *Файл > Новый*.
* **Внешний вид**: **Тема** (тёмная, светлая и темы плагинов) и **цвет акцента**.
* **Холст**: сетка, привязка, связи выбранного поверх остальных, автогруппировка, меню при отпущенной связи.
* **Просмотр кода**: подсветка, номера строк, перенос строк, размер шрифта.
* **Интерфейс**: размер текста.
* **Дополнительно**: как вызываются игровые функции, как устанавливаются хуки.

Вид > Тема быстро меняет оформление.

## Язык

**Вид > Язык** (значок земного шара, чтобы найти его на любом языке) переключает интерфейс между английским, французским, немецким, испанским, итальянским, нидерландским, русским, японским и китайским. Английский — язык по умолчанию. Программа предложит перезапуститься, чтобы применить изменение. Содержимое плагинов (например, описания функций Dear ImGui) остаётся на английском.

## Горячие клавиши

**Сервис > Горячие клавиши…** меняет любое сочетание. По умолчанию:

| Клавиши | Действие |
|---|---|
| Ctrl+Shift+F | Добавить игровую функцию |
| Ctrl+Shift+K | Добавить функцию плагина |
| Ctrl+F | Поиск по графу |
| Ctrl+Z / Ctrl+Y | Отменить / повторить |
| Ctrl+D, Delete, Ctrl+A | Дублировать, удалить, выбрать всё |
| Ctrl+G, Ctrl+Shift+C, Ctrl+L | Группировать, комментарий, упорядочить |
| Ctrl+I | Импорт C++ |
| F, Ctrl+J | Вписать в окно, показать/скрыть вывод |
| Ctrl+E, F5 | Записать в проект, скомпилировать |
| Ctrl+N / O / S | Новый, открыть, сохранить |
| Ctrl+Shift+S | Сохранить как… |
| F1 | Руководства |
