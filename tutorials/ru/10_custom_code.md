# Свой код и импорт C++

Ноды покрывают многое, но не всё. Два запасных выхода не дадут застрять.

## Собственные блоки

* **Custom expression**: любое выражение C++, используемое как значение.
* **Custom statement**: любая инструкция C++ в потоке.

Подключите до восьми входов и ссылайтесь на них как `$a` … `$h` в тексте:

```
sead::Mathf::sqrt($a * $a + $b * $b)
```

## Файлы include

Вкладка **Includes** (внизу) показывает строки `#include` сгенерированного файла. Добавьте заголовки, нужные вашему коду.

## Импорт C++

**Файл > Импорт файла C++…** (Ctrl+I) превращает `.cpp` в граф в той мере, в какой он его понимает. Он читает код, который пишет этот инструмент, и распространённые ручные шаблоны; шаблоны (templates), классы и необычные макросы остаются собственным кодом. Затем проверьте вкладку *Проблемы*.
