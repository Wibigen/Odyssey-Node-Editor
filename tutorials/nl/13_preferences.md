# Voorkeuren, thema's en sneltoetsen

## Voorkeuren (Ctrl+,)

* **Opstarten en bestanden**: wat er bij het starten opent, automatisch opslaan, wat *Bestand > Nieuw* toont.
* **Uiterlijk**: **Thema** (donker, licht, plus thema's van plugins) en **accentkleur**.
* **Canvas**: raster, uitlijnen, koppelingen van de selectie bovenop, automatisch groeperen, het menu bij losgelaten koppelingen.
* **Codevoorbeeld**: markering, regelnummers, regelafbreking, lettergrootte.
* **Interface**: tekstgrootte.
* **Geavanceerd**: hoe spelfuncties worden aangeroepen, hoe hooks worden geïnstalleerd.

Beeld > Thema wijzigt snel het uiterlijk.

## Taal

**Beeld > Taal** (het wereldbolpictogram, zodat je het in elke taal kunt vinden) schakelt de interface tussen Engels, Frans, Duits, Spaans, Italiaans, Nederlands, Russisch, Japans en Chinees. Engels is de standaardtaal. Het programma biedt aan opnieuw te starten om de wijziging toe te passen. Plugininhoud (bijvoorbeeld de beschrijvingen van de Dear ImGui-functies) blijft in het Engels.

## Sneltoetsen

**Extra > Sneltoetsen…** wijzigt elke sneltoets. Standaardwaarden:

| Toets | Actie |
|---|---|
| Ctrl+Shift+F | Spelfunctie toevoegen |
| Ctrl+Shift+K | Pluginfunctie toevoegen |
| Ctrl+F | Zoeken in de graaf |
| Ctrl+Z / Ctrl+Y | Ongedaan maken / opnieuw |
| Ctrl+D, Delete, Ctrl+A | Dupliceren, verwijderen, alles selecteren |
| Ctrl+G, Ctrl+Shift+C, Ctrl+L | Groeperen, commentaar, rangschikken |
| Ctrl+I | C++ importeren |
| F, Ctrl+J | Weergave aanpassen, uitvoer tonen/verbergen |
| Ctrl+E, F5 | Naar project schrijven, compileren |
| Ctrl+N / O / S | Nieuw, openen, opslaan |
| Ctrl+Shift+S | Opslaan als… |
| F1 | Tutorials |
