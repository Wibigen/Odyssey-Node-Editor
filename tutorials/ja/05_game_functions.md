# ゲーム関数の呼び出しとフック

**ゲーム関数…**(Ctrl+Shift+F)をクリックして、Super Mario Odyssey の関数カタログを検索します。

## ブラウザ

* 名前、クラス、説明の一部を入力します。左のカテゴリで絞り込めます。
* 関数を選ぶと、**シグネチャ、戻り値の型、オフセット、シンボル** が表示されます。
* ☆ は **お気に入り** です。**GitHub で開く** は OdysseyDecomp で検索します(実際の動作を読むのに便利です)。

## 呼び出すか、フックするか

| | **この関数を MOD から呼び出す** | **この関数をフック** |
|---|---|---|
| 意味 | *私のグラフがこのゲーム関数を呼ぶ* | *ゲームがこの関数を呼んだとき、私のグラフが実行される* |
| ノード | フローの中のノード | 赤い入口ノード(入力なし) |
| 典型的な用途 | `al::setPos(actor, …)`、`kill`、値の読み取り | 毎フレームのコード実行、攻撃を受けたとき、アイテムを取ったとき |

### 呼び出しの引数

各引数は **ノードを接続** する(値を配線する)か、**固定値**(数値、文字列、bool、`Vector3`(X/Y/Z)、任意の C++ 式)です。

### 結果

値を返す呼び出しは、**その値を変数に保存**(インスペクタで名前を付ける)するか、**値として直接**他のノードで使えます(インスペクタまたは右クリックメニューの *値として使用*)。

## フックのモード

| モード | 実行されるもの |
|---|---|
| **先に元の処理、その後に私のグラフ** | ゲーム関数、その後にあなたのロジック(既定)。 |
| **先に私のグラフ、その後に元の処理** | あなたのロジック、その後にゲームの処理。 |
| **元の処理を置き換える** | あなたのグラフのみ。 |
| **手動** | グラフ内の好きな場所に **Call original (Orig)** ノードを自分で置く。 |

戻り値のある関数で *前* のモードを使うと、**original result** 出力にゲームが返した値が入ります。必要に応じてインスペクタで戻り値の型や引数名を変更します。

## 戻り値の型が違う場合

カタログはヘッダーから戻り値の型を推測します。`void` となっているのに実際は値を返す場合は、戻り値の型の横の **変更…** を使います(確認の警告が出ます)。選択は記憶されます。

## 名前による呼び出し

カタログにないものは **Call by name**(関数)を使います。`sead::Mathf::sqrt(x)` のように、名前で任意の C++ 関数を呼べます。**Get scene object** は `al::getSceneObj<T>(…)` に対応します。

## 呼び出しスタイル

*設定 > 詳細*: 呼び出しは既定で通常の C++(`rs::getPlayerActor(scene)`)、またはアドレス指定です。ノード単位で上書きできます(インスペクタの *呼び出しスタイル*)。フックは既定で **シンボル** でインストールされ、オフセット形式は予備です。
