# はじめに

**Odyssey Node Editor** を使うと、C++ を手で書かずに **Super Mario Odyssey 1.0.0** 用の MOD を作れます。キャンバス上で **ノード** をつなぐと、エディタが [exlaunch](https://github.com/shadowninja108/exlaunch) 用のコードを書きます。コンパイルは、これまでどおりご自身の exlaunch プロジェクトで行います。

## 1 分でわかる考え方

1. **フック** ノードは「ゲームがこの関数を実行したら、私のグラフを実行する」という意味です。
2. その先でノードをつなぎます。ゲーム関数の呼び出し、変数の変更、条件の判定、ループなどです。
3. **C++ コード** タブに結果がリアルタイムで表示されます。
4. **プロジェクトに書き込む** でコードが exlaunch プロジェクトに入り、**コンパイル** でビルドされ、**Ryujinx** タブで MOD 付きのゲームを起動できます。

## 必要なもの

* **OdysseyDecomp** のフォルダ(エディタはシンボル一覧を読み、すべてのゲーム関数を把握します)。
* ビルドできる **exlaunch プロジェクト**(例: SMO-Exlaunch-Base のコピー)。
* *(任意)* テスト用の Ryujinx。

## ウィンドウの構成

| 領域 | 内容 |
|---|---|
| メニューとツールバー | ファイル、編集、ライブラリ、表示、ツール、プラグイン、ヘルプ。よく使うアイコン |
| **ブロック**(左) | 追加できるすべてのブロック(検索可能) |
| **キャンバス**(中央) | グラフ |
| **インスペクタ**(右) | 選択中のノードの設定 |
| **出力**(下) | C++ コード、Includes、問題、ビルド、Ryujinx |

**ヘルプ > インターフェースツアー** でツアーを見てから、チュートリアルを順に読んでください。

1. *プロジェクトの設定*
2. *最初の MOD*
3. *キャンバス*、その後は必要なトピック。

**ご注意:** エディタ自身が Switch 向けにコンパイルすることはなく、ゲームファイルにも触れません。指定したプロジェクトに C++ を書き込むだけです。
