# フロー制御

**Flow** ブロックは、*どの* ノードを *何回* 実行するかを決めます。

| ブロック | 動作 |
|---|---|
| **Branch (if / else)** | 条件 **c**: **then** または **else** の経路を実行し、その後に続行します。 |
| **Switch** | 整数から経路を選びます。ケースは **+** ボタンで小さな枠として編集します。 |
| **For loop** | 経路を N 回繰り返します。インデックスは出力です。 |
| **While loop** | 条件が真の間、繰り返します。 |
| **Return** | 現在の関数またはフックを抜けます(値を返すこともできます)。 |

## フローの読み方

白い矢印をたどります。実行出力が 2 つあるノード(Branch)には 2 つの続きがあり、その後に共通のノードで合流できます。

## ヒント

* ループは短く保ちましょう。フックはゲームのメインスレッドで毎フレーム実行されます。
* 条件が変わったときに **1 回だけ** 実行したい場合は、前の状態を **グローバル変数** に保存します。
* 繰り返し使う処理は自分の関数にまとめます(次のチュートリアル)。
