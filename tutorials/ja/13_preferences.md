# 設定、テーマ、ショートカット

## 設定(Ctrl+,)

* **起動とファイル**: 起動時に開くもの、自動保存、*ファイル > 新規* の内容。
* **外観**: **テーマ**(ダーク、ライト、プラグインのテーマ)と **アクセントカラー**。
* **キャンバス**: グリッド、スナップ、選択中のリンクを前面に表示、自動グループ化、リンクを離したときのメニュー。
* **コードプレビュー**: ハイライト、行番号、折り返し、フォントサイズ。
* **インターフェース**: 文字サイズ。
* **詳細**: ゲーム関数の呼び出し方法、フックのインストール方法。

表示 > テーマで外観をすばやく変更できます。

## 言語

**表示 > 言語**(どの言語でも見つけられるよう地球アイコン付き)で、インターフェースを英語、フランス語、ドイツ語、スペイン語、イタリア語、オランダ語、ロシア語、日本語、中国語から切り替えられます。既定は英語です。変更を反映するため、プログラムが再起動を提案します。プラグインの内容(たとえば Dear ImGui 関数の説明)は英語のままです。

## ショートカット

**ツール > ショートカット…** で各ショートカットを変更できます。既定値:

| キー | 操作 |
|---|---|
| Ctrl+Shift+F | ゲーム関数を追加 |
| Ctrl+Shift+K | プラグイン関数を追加 |
| Ctrl+F | グラフ内を検索 |
| Ctrl+Z / Ctrl+Y | 元に戻す / やり直し |
| Ctrl+D、Delete、Ctrl+A | 複製、削除、すべて選択 |
| Ctrl+G、Ctrl+Shift+C、Ctrl+L | グループ化、コメント、整列 |
| Ctrl+I | C++ をインポート |
| F、Ctrl+J | 全体表示、出力の表示/非表示 |
| Ctrl+E、F5 | プロジェクトに書き込む、コンパイル |
| Ctrl+N / O / S | 新規、開く、保存 |
| Ctrl+Shift+S | 名前を付けて保存… |
| F1 | チュートリアル |
