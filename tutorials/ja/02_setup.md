# プロジェクトの設定

**ツール > 設定**(Ctrl+Shift+,)を開きます。初回はウィンドウが自動で開きます。

## 1. OdysseyDecomp フォルダ

[OdysseyDecomp](https://github.com/MonsterDruide1/OdysseyDecomp) のコピーのフォルダ(`data/file_list.yml` があるもの)を指定します。エディタは **関数カタログ**(約 17,700 関数)を作成します。名前、引数、戻り値の型、オフセット、シンボルが含まれます。これは一度だけ行われ、保存されます。マングルされた名前の読み取りには `c++filt` が必要です。自動検出されますが、同じウィンドウで指定することもできます。

カタログが実際には値を返す関数を `void` と表示している場合は、後で修正できます(*ゲーム関数の呼び出しとフック* を参照)。

## 2. exlaunch プロジェクト

* **プロジェクトフォルダ**: exlaunch プロジェクトのルート(`CMakeLists.txt` があるフォルダ)。Windows パス、`\\wsl$\Ubuntu\home\me\proj`、WSL パスに対応しています。
* **生成ファイル**: コードの書き込み先。空欄 = `src/program/main.cpp` または `src/main.cpp`(存在するほう)。

## 3. ビルドコマンド

既定は `cmake --build build` です。実行場所を選びます: **Windows (cmd)**、**WSL**(Ubuntu などのディストリビューションを選択)、または独自のシェル。未設定の場合、初回の *コンパイル* 時に尋ねられます。

## 4. テスト

下の **Ryujinx** タブを開き、Ryujinx のプログラム、ゲームファイル、MOD 名を一度だけ設定します。*MOD をインストールして起動* でビルド結果が Ryujinx の MOD フォルダにコピーされ、ゲームが起動します。

## 見つからない場合

* **問題** タブ: グラフにまだ足りないもの。
* **ツール > exlaunch ベースを修復**: `build` フォルダを削除して CMake を再実行します(壊れた構成を直します)。
* 設定はいつでも開き直せます。何も失われません。
