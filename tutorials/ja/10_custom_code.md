# カスタムコードと C++ のインポート

ノードで多くはカバーできますが、すべてではありません。2 つの脱出口があります。

## カスタムブロック

* **Custom expression**: 値として使う任意の C++ 式。
* **Custom statement**: フロー内の任意の C++ 文。

最大 8 個の入力を接続し、テキスト内で `$a` … `$h` として参照できます。

```
sead::Mathf::sqrt($a * $a + $b * $b)
```

## include ファイル

下の **Includes** タブには、生成ファイルの `#include` 行が表示されます。自分のコードに必要なヘッダーを追加してください。

## C++ のインポート

**ファイル > C++ ファイルをインポート…**(Ctrl+I)は、理解できる範囲で `.cpp` をグラフに変換します。このツールが書くコードと、一般的な手書きのパターンを読み取ります。テンプレート、クラス、特殊なマクロはカスタムコードのままになります。その後 *問題* タブを確認してください。
