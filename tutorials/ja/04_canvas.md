# キャンバス: ノード、ピン、リンク

## ノードとピン

ノードの左に **入力ピン**、右に **出力ピン** があります。

* **白い矢印のピン** は **実行順序** です。ノードは *in* ピンに接続されたノードの後に実行され、*next* から先に進みます。
* **色付きの丸** は **値** です。色は型(数値、ポインタ、bool、文字列など)で決まります。塗りつぶしは接続済み、空は未接続です。
* 未接続の入力には、インスペクタで入力する **固定値**(`= 60`)が表示されます。

## 接続する

* **ピンから別のピンへドラッグ** します(出力から入力へ)。
* 値の出力は **複数の** 入力に使えます。実行の出力は **1 つの** 次のノードにつながります。
* **空いた場所でリンクを離す** と、メニューに *ゲーム関数…*、*プラグイン関数…*(プラグインにカタログがある場合)、および適合するすべてのブロックが表示され、新しいノードが作成されて接続されます。(設定でオフにできます。)
* ノードを選んで **Delete** を押すと削除されます。*インスペクタ > 切断* はリンクだけを削除します。

## 移動と操作

| 操作 | 方法 |
|---|---|
| ズーム | マウスホイール(Ctrl +/-) |
| 移動 | **中ボタン** を押したままドラッグ |
| すべて表示 | **F** |
| 複数選択 | 空いた場所で矩形ドラッグ。すべては Ctrl+A |
| 複製 / 削除 | Ctrl+D / Delete |
| 元に戻す / やり直し | Ctrl+Z / Ctrl+Y |
| ノードを探す | グラフ内で Ctrl+F(検索アイコン) |
| 整列 | Ctrl+L でノードを自動配置 |

## ブロックの追加

* ブロックを **ダブルクリック** するか、**ブロック** リストから **ドラッグ** します。
* 空のキャンバスで **右クリック** すると同じ選択肢と *ここにコメントを追加* が出ます。
* リスト上部のフィルタ欄で名前と説明を検索できます。

## 色

ノードの種類ごとにヘッダーの色が異なります。**プラグイン** 由来のノードには、プラグインの色の控えめな光彩が付き、ひと目で見分けられます。
