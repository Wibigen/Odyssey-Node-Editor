# トラブルシューティング

| 問題 | 試すこと |
|---|---|
| *関数カタログが空* | ツール > 設定: OdysseyDecomp フォルダ(`data/file_list.yml` があるもの)を選んでカタログを抽出します。 |
| 関数が `void` になっているが、そうではないはず | 戻り値の型を変更します(*ゲーム関数の呼び出しとフック* を参照)。 |
| *問題* タブに何か表示される | 行をダブルクリックするとノードが選択されます。多くは未接続の入力か、存在しない変数です。 |
| コンパイルでヘッダーが見つからない | **Includes** タブで追加するか、プロジェクトの include パスを修正します。 |
| ビルドフォルダが壊れている | ツール > **exlaunch ベースを修復**。 |
| ゲームで何も起きない | フックはインストールされていますか(シンボルは正しいですか)? MOD フォルダは Ryujinx が読み込むものですか(Ryujinx タブ)? 他の MOD が無効になっていますか? |
| ゲームがクラッシュする | ポインタが null か、オフセットが合っていません。**Is null?** の判定を追加し、バージョン 1.0.0 のオフセットを確認してください。 |
| ショートカットが効かない | ツール > ショートカット: 変更されている可能性があります。 |
| ウィンドウのレイアウトがおかしい | 表示: 出力パネルを表示(Ctrl+J)し、パネルを好きな場所にドラッグし直します。 |

問題を報告するときは、**ビルド** ログ(ビルドログを保存)を添付してください。
