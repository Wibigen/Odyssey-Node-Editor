# 変数、値、計算

## 変数(カテゴリ *変数*)

| ブロック | 用途 |
|---|---|
| **Declare variable** | ローカル変数(型、名前、任意の初期値)。宣言したフローの中だけで有効です。 |
| **Set variable** | 新しい値を代入します。 |
| **Get variable** | 現在の値を読み取ります(値の出力で、実行ピンはありません)。 |
| **Global variable** | フレームや呼び出しをまたいで値を保持します。関数の外の *Declare variable* もグローバルになります。 |
| **Constant (value)** | 固定の数値、文字列、bool、または入力した任意の C++ 値。 |

インスペクタの **詳細** で修飾子(`static`、`const` など)や配列(サイズと内容)を設定できます。

> 分岐の中で宣言したローカル変数は、その分岐の中だけに存在します(C++ と同じです)。

## 計算とロジック

小さな四角で表示されます。

* **Math (A + B)**: 2 つの値に対する `+ - * / %`(型を選択)。
* **Compare**: `== != < > <= >=`、bool を返します。
* **Logic**: AND / OR。**NOT** は bool を反転します。

結果は **Branch** の条件、変数、呼び出しの引数につなぎます。

## 固定値かリンクか

各入力ピンは、ノードに **接続** するか **固定値**(インスペクタで入力)を持たせられます。接続すると固定値は隠れます。

## 型

ピンの色は型を示しますが、エディタはリンク間のポインタ型を検査しません(たとえば `StageScene*` から `al::LiveActor*` は C++ のエラーで、ビルド時にわかります)。変換が必要なときは **Cast**(ポインタとメモリ)を使います。
