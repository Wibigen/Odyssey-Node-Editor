# プラグイン

プラグインは **ノード**、**関数カタログ**、**テーマ**、**テンプレート**、**チュートリアル** を追加します。

## プラグインブラウザ

**プラグイン > プラグインブラウザ**(Ctrl+Shift+P): 各プラグインの画像、作者、バージョン、内容を表示します。**有効化 / 無効化**、**インストール…**(`.zip` / `.odnp` またはフォルダ)、**削除**、**新規プラグイン…**(編集用のひな形)、**フォルダを表示**。

同梱: *標準入出力*、*文字列*、*追加テーマ*、**Dear ImGui**(既定ではオフ)。

## プラグインが追加するものを使う

* ノードは **ブロック** リストのプラグインのカテゴリに表示され、キャンバス上では控えめな色付きの光彩が付きます。
* カタログは **プラグイン関数…**(Ctrl+Shift+K、ブロックリスト上のボタン、またはリンクを離したときのメニュー)で開きます。
* テンプレート: **ファイル > テンプレートから新規作成**。
* チュートリアル: **チュートリアル** ウィンドウの *プラグインのチュートリアル* セクション。

## プロジェクトを変更するプラグイン

一部のプラグイン(Dear ImGui)は、exlaunch プロジェクトにファイルと CMake の行を必要とします。エディタは有効化時にそれを **提案** します。何も上書きされず、`CMakeLists.txt` のバックアップが保持され、*プラグインブラウザ > exlaunch ベース…* で追加したものだけを正確に取り除けます。

## 安全性

`plugin.py` ファイルを持つプラグインは、エディタと同じ権限で Python を実行します。信頼できる人のプラグインだけをインストールしてください。

## 自分で作る

`PLUGINS.md`(形式、ノードのテンプレート、テーマ、ヘルプページ、設定)を参照してください。
