# 最初の MOD

目標: プレイ中に **1 秒に 1 回** 何かを実行すること。サンプルグラフも同じことをしますが、ここでは各部分を理解するために自分で作ります。

## 1. ゲーム関数をフックする

1. **ゲーム関数…**(赤いボタン、または Ctrl+Shift+F)をクリックします。
2. `exePlay` を検索し、**StageScene::exePlay**(プレイ中に毎フレーム実行される関数)を選びます。
3. **この関数をフック** を選び、モードは *先に元の処理、その後に私のグラフ* のままにして、**グラフに追加** をクリックします。

赤い **Hook StageScene::exePlay** ノードが表示されます。白い **next** ピンがあなたのロジックの開始点です。

## 2. フレームを数える

1. **グローバル変数**(変数)を追加します。型は `int`、名前は `frames`、初期値は `0`。グローバル変数はフレームをまたいで値を保持します。
2. **Set variable** を追加し、`frames` を選んで **hook next → in** をつなぎます。
3. **Get variable** `frames` と、`int` 型の **Math (A + B)**(B = `1`)を追加し、*Get → A*、*Math out → Set v* をつなぎます。

## 3. 60 フレームごとに実行する

1. Set variable の後ろに **Branch (if / else)** を追加します。
2. 条件: **Compare** `(frames % 60) == 0`(`%` と 60 を設定した *Math* ノードの出力を、`== 0` の *Compare* に入れます)。結果を Branch の **c** ピンにつなぎます。
3. **then** の経路に好きな処理を置きます。たとえば **Custom statement** `/* ここに自分のコード */` や、ゲーム関数の呼び出しです。

## 4. コードを見る

**C++ コード** タブを開くと、フック、変数、`if` が表示されます。ノードを選ぶと、その行が強調表示されます。

## 5. ビルドして試す

1. **問題** タブは空ですか? 問題ありません。
2. **プロジェクトに書き込む**(Ctrl+E)、続いて **コンパイル**(F5)。
3. **Ryujinx** タブ > *MOD をインストールして起動*。

> もっと手早く始めるには、**ファイル > テンプレートから新規作成**(または 設定 > 起動時に開く のサンプルグラフ)で完成済みのグラフが得られます。
