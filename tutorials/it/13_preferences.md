# Preferenze, temi e scorciatoie

## Preferenze (Ctrl+,)

* **Avvio e file**: cosa si apre all'avvio, salvataggio automatico, cosa mostra *File > Nuovo*.
* **Aspetto**: **Tema** (scuro, chiaro, più i temi dei plugin) e **colore di accento**.
* **Tela**: griglia, aggancio, collegamenti della selezione in primo piano, raggruppamento automatico, il menu al rilascio di un collegamento.
* **Anteprima del codice**: evidenziazione, numeri di riga, a capo automatico, dimensione del carattere.
* **Interfaccia**: dimensione del testo.
* **Avanzate**: come vengono chiamate le funzioni del gioco e come vengono installati gli hook.

Visualizza > Tema cambia rapidamente l'aspetto.

## Lingua

**Visualizza > Lingua** (l'icona del globo, così la trovi in qualsiasi lingua) cambia l'interfaccia tra inglese, francese, tedesco, spagnolo, italiano, olandese, russo, giapponese e cinese. L'inglese è la lingua predefinita. Il programma propone di riavviarsi per applicare la modifica. I contenuti dei plugin (per esempio le descrizioni delle funzioni di Dear ImGui) restano in inglese.

## Scorciatoie da tastiera

**Strumenti > Scorciatoie da tastiera…** modifica qualsiasi scorciatoia. Valori predefiniti:

| Tasto | Azione |
|---|---|
| Ctrl+Maiusc+F | Aggiungi funzione del gioco |
| Ctrl+Maiusc+K | Aggiungi funzione di plugin |
| Ctrl+F | Cerca nel grafo |
| Ctrl+Z / Ctrl+Y | Annulla / ripeti |
| Ctrl+D, Canc, Ctrl+A | Duplica, elimina, seleziona tutto |
| Ctrl+G, Ctrl+Maiusc+C, Ctrl+L | Raggruppa, commenta, disponi |
| Ctrl+I | Importa C++ |
| F, Ctrl+J | Adatta la vista, mostra/nascondi output |
| Ctrl+E, F5 | Scrivi nel progetto, compila |
| Ctrl+N / O / S | Nuovo, apri, salva |
| Ctrl+Maiusc+S | Salva con nome… |
| F1 | Tutorial |
