# Gruppi, commenti e la libreria

## Gruppi

Seleziona dei nodi e premi **Ctrl+G**: compare un riquadro con un titolo. Trascina la barra del titolo per spostare tutti i nodi insieme. Modifica nome, colore e membri dal menu del gruppo. Preferenza: rilasciare un nodo dentro un riquadro lo aggiunge al gruppo.

## Commenti

**Ctrl+Maiusc+C** (o clic destro sulla tela > *Commenta qui*) aggiunge una nota di testo libero.

## Mettere in ordine

**Ctrl+L** dispone il grafo automaticamente (tutti i nodi, o solo la selezione).

## La libreria

Riutilizza il tuo lavoro tra i progetti.

* **Libreria > Salva la selezione nella libreria…** memorizza una funzione (con tutto ciò che usa) o un modello come file `.odnf` nella tua cartella dati.
* Le voci salvate compaiono in fondo all'elenco **Blocchi** e nel menu **Libreria**. Fai doppio clic o trascinane una per inserirla (dentro un gruppo).

## File

* **File > Salva** (Ctrl+S) scrive nel file su cui stai lavorando: il suo nome è nel titolo della finestra, e un punto (•) indica modifiche non salvate. La prima volta chiede un nome. **Salva con nome…** (Ctrl+Maiusc+S) salva con un altro nome. I grafi sono file `.odn`.
* **File > Apri recenti** elenca i tuoi ultimi file. Il salvataggio automatico conserva anche la tua sessione, compreso il file che stavi modificando.
* **File > Salva come grafo di avvio**: ciò che apre **File > Nuovo**.
* **Nuovo da modello**: grafi pronti (per esempio dai plugin).
