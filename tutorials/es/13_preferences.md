# Preferencias, temas y atajos

## Preferencias (Ctrl+,)

* **Inicio y archivos**: qué se abre al arrancar, guardado automático, qué muestra *Archivo > Nuevo*.
* **Apariencia**: **Tema** (oscuro, claro, más los temas de plugins) y **color de acento**.
* **Lienzo**: cuadrícula, ajuste, enlaces de la selección encima, agrupación automática, el menú al soltar un enlace.
* **Vista previa del código**: resaltado, números de línea, ajuste de línea, tamaño de fuente.
* **Interfaz**: tamaño del texto.
* **Avanzado**: cómo se llama a las funciones del juego y cómo se instalan los hooks.

Ver > Tema cambia el aspecto rápidamente.

## Idioma

**Ver > Idioma** (el icono de globo, para encontrarlo en cualquier idioma) cambia la interfaz entre inglés, francés, alemán, español, italiano, neerlandés, ruso, japonés y chino. El inglés es el idioma por defecto. El programa ofrece reiniciar para aplicar el cambio. El contenido de los plugins (por ejemplo las descripciones de las funciones de Dear ImGui) permanece en inglés.

## Atajos de teclado

**Herramientas > Atajos de teclado…** cambia cualquier atajo. Valores por defecto:

| Tecla | Acción |
|---|---|
| Ctrl+Mayús+F | Añadir función del juego |
| Ctrl+Mayús+K | Añadir función de plugin |
| Ctrl+F | Buscar en el grafo |
| Ctrl+Z / Ctrl+Y | Deshacer / rehacer |
| Ctrl+D, Supr, Ctrl+A | Duplicar, eliminar, seleccionar todo |
| Ctrl+G, Ctrl+Mayús+C, Ctrl+L | Agrupar, comentar, organizar |
| Ctrl+I | Importar C++ |
| F, Ctrl+J | Ajustar la vista, mostrar/ocultar la salida |
| Ctrl+E, F5 | Escribir en el proyecto, compilar |
| Ctrl+N / O / S | Nuevo, abrir, guardar |
| Ctrl+Mayús+S | Guardar como… |
| F1 | Tutoriales |
