# 设置、主题和快捷键

## 设置(Ctrl+,)

* **启动和文件**:启动时打开什么、自动保存、*文件 > 新建* 显示什么。
* **外观**:**主题**(深色、浅色以及插件主题)和 **强调色**。
* **画布**:网格、吸附、所选连线置顶、自动分组、松开连线时的菜单。
* **代码预览**:高亮、行号、自动换行、字号。
* **界面**:文字大小。
* **高级**:如何调用游戏函数、如何安装钩子。

视图 > 主题可快速更改外观。

## 语言

**视图 > 语言**(带地球图标,方便你在任何语言下找到它)可在英语、法语、德语、西班牙语、意大利语、荷兰语、俄语、日语和中文之间切换界面。默认语言为英语。程序会提示重启以应用更改。插件内容(例如 Dear ImGui 函数的描述)仍为英文。

## 快捷键

**工具 > 快捷键…** 可更改任意快捷键。默认值:

| 按键 | 操作 |
|---|---|
| Ctrl+Shift+F | 添加游戏函数 |
| Ctrl+Shift+K | 添加插件函数 |
| Ctrl+F | 在图中搜索 |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做 |
| Ctrl+D、Delete、Ctrl+A | 复制、删除、全选 |
| Ctrl+G、Ctrl+Shift+C、Ctrl+L | 分组、注释、整理 |
| Ctrl+I | 导入 C++ |
| F、Ctrl+J | 适应窗口、显示/隐藏输出 |
| Ctrl+E、F5 | 写入项目、编译 |
| Ctrl+N / O / S | 新建、打开、保存 |
| Ctrl+Shift+S | 另存为… |
| F1 | 教程 |
