# 调用和钩住游戏函数

点击 **游戏函数…**(Ctrl+Shift+F)搜索 Super Mario Odyssey 的函数目录。

## 浏览器

* 输入名称、类名或描述的一部分。左侧的分类可缩小列表范围。
* 选择一个函数可查看其 **签名、返回类型、偏移和符号**。
* 星标 ☆ 表示 **收藏**;**在 GitHub 上打开** 会在 OdysseyDecomp 中搜索(便于阅读它实际做了什么)。

## 调用还是钩住?

| | **在我的 Mod 中调用此函数** | **钩住此函数** |
|---|---|---|
| 含义 | *我的图调用这个游戏函数* | *当游戏调用它时,运行我的图* |
| 节点 | 流程中的一个节点 | 红色入口节点(无输入) |
| 典型用途 | `al::setPos(actor, …)`、`kill`、读取一个值 | 每帧运行你的代码、被击中时、拾取物品时 |

### 调用的参数

每个参数要么 **连接节点**(接入一个值),要么是 **固定值**:数字、文本、bool、`Vector3`(X/Y/Z 字段)或任意 C++ 表达式。

### 结果

返回值的调用可以 **把它保存到变量**(在检查器中命名),或 **直接作为值** 用于另一个节点(检查器或右键菜单中的 *用作值*)。

## 钩子模式

| 模式 | 执行内容 |
|---|---|
| **先执行原函数,再执行我的图** | 游戏函数,然后是你的逻辑(默认)。 |
| **先执行我的图,再执行原函数** | 你的逻辑,然后是游戏的逻辑。 |
| **替换原函数** | 只运行你的图。 |
| **手动** | 你自己在图中想要的位置放置 **Call original (Orig)** 节点。 |

在带返回值的 *之前* 模式下,**original result** 输出提供游戏返回的值。必要时在检查器中修改返回类型或参数名。

## 返回类型不对?

目录根据头文件推测返回类型。如果某函数标为 `void` 但实际有返回值,请使用返回类型旁的 **更改…**(会有确认警告)。该选择会被记住。

## 按名称调用

目录中没有的内容请使用 **Call by name**(函数):按名称调用任意 C++ 函数,例如 `sead::Mathf::sqrt(x)`。**Get scene object** 对应 `al::getSceneObj<T>(…)`。

## 调用风格

*设置 > 高级*:调用默认是普通 C++(`rs::getPlayerActor(scene)`),或按地址。单个节点可以覆盖此设置(检查器中的 *调用风格*)。钩子默认 **按符号** 安装;偏移形式是备选。
