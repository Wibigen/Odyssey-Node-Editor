# 画布:节点、引脚和连线

## 节点和引脚

节点左侧是 **输入引脚**,右侧是 **输出引脚**。

* **带白色箭头的引脚** 表示 **执行顺序**:节点在连接到其 *in* 引脚的节点之后运行,并通过 *next* 继续。
* **彩色圆圈** 是 **值**。颜色取决于类型(数字、指针、bool、文本……)。实心圆表示已连接,空心表示空闲。
* 未连接的输入会显示一个在检查器中输入的 **固定值**(`= 60`)。

## 连接

* **从一个引脚拖到另一个引脚**(从输出到输入)。
* 一个值输出可以供给 **多个** 输入;一个执行输出只通向 **一个** 下一节点。
* **在空白处松开连线**:弹出的菜单提供 *游戏函数…*、*插件函数…*(当插件带有目录时)以及所有适配的块;新节点会自动创建并连接。(可在设置中关闭。)
* 选中节点并按 **Delete** 删除;*检查器 > 断开连接* 只删除它的连线。

## 导航

| 操作 | 方法 |
|---|---|
| 缩放 | 鼠标滚轮(Ctrl +/-) |
| 平移 | 按住 **鼠标中键** 拖动 |
| 显示全部 | **F** |
| 多选 | 在空白处拖出矩形;Ctrl+A 全选 |
| 复制 / 删除 | Ctrl+D / Delete |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Y |
| 查找节点 | 在图中按 Ctrl+F(搜索图标) |
| 整理 | Ctrl+L 自动排列节点 |

## 添加块

* **双击** 一个块,或从 **块** 列表中 **拖动** 它。
* 在空白画布上 **右键** 可得到相同的选择,另有 *在此添加注释*。
* 列表上方的筛选框可搜索名称和描述。

## 颜色

每种节点都有各自的标题颜色。来自 **插件** 的节点还带有一圈插件颜色的柔和光晕,让你一眼就能认出。
