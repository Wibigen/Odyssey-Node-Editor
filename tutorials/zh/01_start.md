# 开始使用

借助 **Odyssey Node Editor**,无需手写 C++ 就能为 **Super Mario Odyssey 1.0.0** 制作 Mod。你在画布上连接 **节点**,编辑器为你生成 [exlaunch](https://github.com/shadowninja108/exlaunch) 代码。编译仍然在你自己的 exlaunch 项目中进行。

## 一分钟了解思路

1. **钩子** 节点表示:*“当游戏执行这个函数时,运行我的图”*。
2. 然后连接节点:调用游戏函数、修改变量、判断条件、编写循环。
3. **C++ 代码** 标签页实时显示结果。
4. **写入项目** 把代码放进你的 exlaunch 项目,**编译** 进行构建,**Ryujinx** 标签页用你的 Mod 启动游戏。

## 你需要准备

* 一个 **OdysseyDecomp** 文件夹(编辑器读取符号列表,以了解每个游戏函数)。
* 一个可以构建的 **exlaunch 项目**(例如 SMO-Exlaunch-Base 的副本)。
* *(可选)* 用于测试的 Ryujinx。

## 窗口布局

| 区域 | 说明 |
|---|---|
| 菜单和工具栏 | 文件、编辑、库、视图、工具、插件、帮助;最常用的图标 |
| **块**(左侧) | 所有可添加的块,可搜索 |
| **画布**(中间) | 你的图 |
| **检查器**(右侧) | 所选节点的设置 |
| **输出**(底部) | C++ 代码、Includes、问题、构建、Ryujinx |

选择 **帮助 > 界面导览** 可以参加导览,然后按顺序阅读教程:

1. *设置项目*
2. *你的第一个 Mod*
3. *画布*,之后是你需要的主题。

**请注意:** 编辑器自己从不为 Switch 编译,也从不触碰游戏文件:它只是把 C++ 写入你指定的项目。
