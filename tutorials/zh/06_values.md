# 变量、值和数学运算

## 变量(分类 *变量*)

| 块 | 用途 |
|---|---|
| **Declare variable** | 局部变量(类型、名称、可选初始值)。只在声明它的流程中有效。 |
| **Set variable** | 赋予新值。 |
| **Get variable** | 读取当前值(值输出,没有执行引脚)。 |
| **Global variable** | 在帧与调用之间保留其值。函数外的 *Declare variable* 也会变成全局变量。 |
| **Constant (value)** | 固定的数字、文本、bool,或你输入的任意 C++ 值。 |

在检查器中使用 **高级** 设置限定符(`static`、`const` 等)和数组(大小和内容)。

> 在分支中声明的局部变量只存在于该分支(与 C++ 相同)。

## 数学和逻辑

显示为小方块:

* **Math (A + B)**:对两个值进行 `+ - * / %`(选择类型)。
* **Compare**:`== != < > <= >=`,返回 bool。
* **Logic**:AND / OR;**NOT** 反转 bool。

把结果连接到 **Branch** 的条件、变量或调用的参数。

## 固定值还是连线?

每个输入引脚都可以 **连接** 到节点,或设置 **固定值**(在检查器中输入)。连接后会隐藏其固定值。

## 类型

引脚颜色表示类型;编辑器不会检查连线之间的指针类型(例如 `StageScene*` 到 `al::LiveActor*` 是 C++ 错误,构建时才会看到)。需要转换时使用 **Cast**(指针与内存)。
