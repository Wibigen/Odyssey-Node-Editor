# 流程控制

**Flow** 块决定 *哪些* 节点运行以及运行 *多少次*。

| 块 | 作用 |
|---|---|
| **Branch (if / else)** | 条件 **c**:执行 **then** 或 **else** 路径,然后继续。 |
| **Switch** | 根据整数选择路径;用 **+** 按钮以小框形式编辑各个 case。 |
| **For loop** | 重复路径 N 次;索引是一个输出。 |
| **While loop** | 条件为真时重复。 |
| **Return** | 离开当前函数或钩子,可附带一个值。 |

## 阅读流程

沿着白色箭头走。有两个执行输出的节点(Branch)有两条可能的后续路径,之后可以在公共节点汇合。

## 提示

* 保持循环简短:钩子在游戏主线程上运行,每帧一次。
* 若要在条件变化时只做 **一次** 某事,请把上一次的状态保存在 **全局变量** 中。
* 把反复出现的想法封装成你自己的函数(下一篇教程)。
