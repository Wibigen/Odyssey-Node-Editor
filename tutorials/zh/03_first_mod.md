# 你的第一个 Mod

目标:游戏过程中 **每秒执行一次** 某件事。示例图就是这样做的;这里你亲自搭建,以便了解每个部分。

## 1. 钩住一个游戏函数

1. 点击 **游戏函数…**(红色按钮,或 Ctrl+Shift+F)。
2. 搜索 `exePlay`,选择 **StageScene::exePlay**(你游玩时每帧都会运行)。
3. 选择 **钩住此函数**,保持模式为 *先执行原函数,再执行我的图*,点击 **添加到图**。

会出现一个红色的 **Hook StageScene::exePlay** 节点。白色的 **next** 引脚是你逻辑的起点。

## 2. 统计帧数

1. 添加一个 **全局变量**(变量):类型 `int`,名称 `frames`,初始值 `0`。全局变量会在帧与帧之间保留其值。
2. 添加 **Set variable**,选择 `frames`,连接 **hook next → in**。
3. 添加 **Get variable** `frames` 和类型为 `int` 的 **Math (A + B)**(B = `1`);连接 *Get → A*、*Math out → Set v*。

## 3. 每 60 帧执行一次

1. 在 Set variable 之后添加 **Branch (if / else)**。
2. 条件:**Compare** `(frames % 60) == 0`(一个设为 `%` 和 60 的 *Math* 节点,输出到 `== 0` 的 *Compare*)。把结果连到 Branch 的 **c** 引脚。
3. 在 **then** 路径上放你想做的事,例如 **Custom statement** `/* 我的代码 */`,或一次游戏函数调用。

## 4. 查看代码

打开 **C++ 代码** 标签页:钩子、变量和 `if` 都在其中。选中一个节点,它对应的行会高亮。

## 5. 构建并试玩

1. **问题** 标签页是空的吗?很好。
2. **写入项目**(Ctrl+E),然后 **编译**(F5)。
3. **Ryujinx** 标签页 > *安装 Mod 并启动*。

> 更快上手:**文件 > 从模板新建**(或 设置 > 启动时打开 中的示例图)会给你一个现成的图。
