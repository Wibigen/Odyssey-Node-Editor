# 故障排除

| 问题 | 可以尝试的做法 |
|---|---|
| *函数目录为空* | 工具 > 设置:选择你的 OdysseyDecomp 文件夹(含 `data/file_list.yml`)并提取目录。 |
| 某函数返回 `void`,但不应如此 | 更改返回类型(参见 *调用和钩住游戏函数*)。 |
| *问题* 标签页显示了内容 | 双击某行即可选中节点。通常是未连接的输入或缺失的变量。 |
| 编译找不到头文件 | 在 **Includes** 标签页添加,或修正项目的 include 路径。 |
| 构建文件夹损坏 | 工具 > **修复 exlaunch 基础**。 |
| 游戏中没有任何反应 | 钩子是否已安装(符号正确吗)?Mod 文件夹是 Ryujinx 加载的那个吗(Ryujinx 标签页)?是否禁用了其他 Mod? |
| 游戏崩溃 | 指针为 null 或偏移不对。添加 **Is null?** 检查;确认 1.0.0 版本的偏移。 |
| 快捷键无效 | 工具 > 快捷键:它可能已被更改。 |
| 窗口布局很奇怪 | 视图:显示输出面板(Ctrl+J);把面板拖回你想要的位置。 |

报告问题时,请附上 **构建** 日志(保存构建日志)。
