# 自定义代码与导入 C++

节点能覆盖很多情况,但不是全部。两个应急出口可以让你继续前进。

## 自定义块

* **Custom expression**:任意 C++ 表达式,用作值。
* **Custom statement**:流程中的任意 C++ 语句。

最多连接八个输入,并在文本中以 `$a` … `$h` 引用:

```
sead::Mathf::sqrt($a * $a + $b * $b)
```

## Include 文件

底部的 **Includes** 标签页显示生成文件的 `#include` 行。请添加你的代码所需的头文件。

## 导入 C++

**文件 > 导入 C++ 文件…**(Ctrl+I)会在其能理解的范围内把 `.cpp` 转换成图。它能读取本工具生成的代码和常见的手写模式;模板、类和不常见的宏会保留为自定义代码。之后请检查 *问题* 标签页。
